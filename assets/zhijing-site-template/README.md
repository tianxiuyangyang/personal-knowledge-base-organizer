# 知境 · 个人知识库网站

这是本知识库的可视化网站版本。无需构建工具。

## 启动

```powershell
cd "E:\张睿琛文件\个人知识库\知识库网站"
python -m http.server 8080
```

浏览器访问：`http://localhost:8080`

## 功能

- 高级感知识仪表盘，含项目、领域、地图、资源、日记、周度回顾
- 可操作的收件箱、任务、新建笔记与快捷指令（`Ctrl/Cmd + K`）
- 深色模式与响应式布局
- 使用浏览器 LocalStorage 保存交互数据

## 知识空间（新增）

打开侧边栏的 **知识地图** 即可进入沉浸式知识空间：

- 在巨大画布中拖动空白处平移，滚轮缩放网络。
- 点击节点可查看与编辑标题、类型和知识内容。
- 拖动节点可以重新组织你的知识脉络。
- 在空白处双击，或点击「新建节点」，即可创建新知识。
- 在编辑面板中选择「连接到」可将两个节点建立关联。
- 节点网络会保存到浏览器的 LocalStorage；刷新网页后仍会保留。

### 首页入口与全屏

首页已将「知识地图」设为核心项目入口：可直接点击 **进入知识空间**；点击 **全屏漫游**，或知识空间页右上角的 **全屏沉浸**，即可让网络画布占据整个屏幕。按 `Esc` 可退出全屏。
